Политика конфиденциальности Infinity Pass

Дата вступления в силу: 5 ноября 2026

Эта политика описывает, какие данные собирает мобильное приложение Infinity Pass (далее — «Приложение»), зачем и как мы их используем. Приложение разработано ООО «PRO SFERA ECO SYS» (далее — «мы»). Политика действует для Приложения на Android (пакет uz.infinitypass.app) и iOS (bundle ID client.infinitypass.uz).

1. Какие данные мы собираем

1.1 Аккаунт

Имя и номер телефона. Вход в Приложение выполняется через Sfere ID — единый аккаунт экосистемы PRO SFERE. Эти данные нужны, чтобы создать ваш аккаунт и показать профиль.

1.2 Платёжные данные

Данные банковской карты Uzcard или Humo, которую вы привязываете для оплаты и автопродления подписки. Номер карты передаётся платёжному партнёру, который обрабатывает платёж. В Приложении карта показывается только в замаскированном виде.

1.3 Покупки

История подписок, покупок, операций с токенами и чеки. Они нужны, чтобы показать вашу подписку, баланс токенов и историю транзакций.

1.4 Геолокация

Точное местоположение — только когда Приложение открыто и только с вашего разрешения. Оно нужно, чтобы показать ближайшие заведения-партнёры на карте. Разрешение можно отозвать в настройках устройства; карта при этом продолжит работать без определения вашего положения.

1.5 Фото

Изображения из галереи — только те, которые вы сами выбираете, чтобы прикрепить скриншоты к заданиям программы для инфлюенсеров.

1.6 Идентификаторы

Идентификатор пользователя и токен push-уведомлений устройства — для работы аккаунта и отправки уведомлений.

Мы не используем данные для рекламы, не продаём их и не передаём рекламным сетям. Приложение не собирает рекламный идентификатор устройства.

2. Кому мы передаём данные

  • Sfere ID (экосистема PRO SFERE) — для входа в аккаунт.
  • Платёжный партнёр — для проведения оплаты по картам Uzcard и Humo.
  • Google Firebase Cloud Messaging — для доставки push-уведомлений.
  • Заведения-партнёры — видят факт оплаты по вашему QR-коду. Данные вашей карты им не передаются.

3. Безопасность

Все данные передаются по зашифрованному соединению (HTTPS). Доступ к данным есть только у сотрудников, которым он нужен для работы сервиса.

4. Хранение и удаление

Мы храним данные, пока у вас есть аккаунт. После удаления аккаунта персональные данные удаляются в течение 30 дней. Записи о платежах мы храним столько, сколько требует законодательство Республики Узбекистан.
